# NutriFit

Sistema web para acompanhamento nutricional e treinos personalizados.

## Integrantes

- João Pedro Carneiro da Fonseca
- Gabriel Leão

## Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring Web MVC
- Thymeleaf
- Spring Data JPA
- Maven
- H2
- MySQL
- Lombok
- GitLab

## Estrutura de diretórios

```text
src/main/java/br/edu/nutrifit
├── controller
├── dto
├── model
├── repository
├── service
└── NutriFitApplication.java

src/main/resources
├── application.properties
├── application-dev.properties
├── application-prod.properties
├── static
│   ├── css
│   └── js
└── templates
```

## Funcionalidades previstas

- Dashboard
- Cadastro de usuários
- Login
- CRUD de refeições
- CRUD de planos alimentares
- Controle de peso e altura
- Cálculo de calorias
- Acompanhamento de metas
- Agendamento
- Treinos personalizados

## Funcionalidade extra escolhida

- Acompanhamento do consumo de água diário pelo usuário.
